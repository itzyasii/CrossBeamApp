# Reviewer instructions

CrossBeam does not require an account or external server. Full review requires two devices on the same local network: one Android phone/tablet and either another Android device or Android TV.

1. Install CrossBeam on both devices.
2. Allow Nearby Wi-Fi/Bluetooth/location permissions requested for discovery on that Android version.
3. On Android TV, open the pairing screen and scan its QR code from the phone.
4. Select a file on the phone or share a file to CrossBeam from Gallery/Files.
5. Select the discovered receiver and start the transfer.
6. Accept the incoming request on the receiving device.
7. Confirm progress, completion, saved output, and transfer history.

No login credentials are required. If multicast or peer discovery is restricted by the review network, use a private Wi-Fi hotspot shared by the two review devices.
